## Method
I rendered 6 French lines through the real extension path in Playwright Chromium: popup page → SW → offscreen document → Piper worker, 4 threads. The lines were neutral, excited, question, a long 25-word sentence, a caps shout, and a line ending softly on "…tu sais". Each voice was rendered at Expression 0 and at 0.7, with scene arousal 0.75. The metrics are in `tests/e2e/m-metrics.ts` and are computed in Node on the returned WAVs:
- **clicks:** second-difference spikes larger than 8× their local 5 ms RMS.
- **gaps:** runs of near-zero samples of at least 1.5 ms inside speech.
- **breaks/s:** drops from speech to −45 dB, on a 2.5 ms envelope. This is the "cutting" metric.
- **dips:** short −35 dB holes with loud speech on both sides.
- **tail dB:** the last 10 ms compared with the line's RMS. A value of −30 dB or more means the line stops while it is still sounding.
- **HNR** and **spectral flatness** of voiced frames. These are the clarity metrics.
- **F0 range, octave jumps, clipping and RTF.**

The raw numbers are in `research/samples/v122/measurements.json`, `noise-grid.json` and `mls-scan.json`.

## Diagnosis (Tom, v1.2.1 code)
| Expr 0 → 0.7 | Tom | Pierre | Siwis |
|---|---|---|---|
| Sample rate | 44.1 kHz (handled correctly; no resampling or playback-rate bug) | 22.05 kHz | 22.05 kHz |
| **Breaks/s ("cutting")** | **2.33 → 2.19** | 0.79 → 0.63 | 1.24 → 1.01 |
| **Spectral flatness (noise)** | **0.017 → 0.019** | 0.008 | 0.005 |
| **HNR dB (clarity)** | **6.8 → 6.6** | 7.9 → 7.6 | 10.9 → 10.5 |
| Clicks (6 lines) | 12 → 14 | 1 → 0 | 0 |
| Gaps in speech | 0 → **2** | 0 | 1 → 0 |
| Dips | 3 → **9** | 2 | 1 |
| Tail, last 10 ms | **−32 / −29 dB (cut while sounding)** | −26 / −25 dB | −33 / −31 dB |
| Octave jumps | 1 → 0 | 0 | 0 |
| Clipping | 0 % | 0 % | 0 % |
| RTF max | 0.25 → 0.28 | 0.09 → 0.12 | 0.08 → 0.34 (cold) |

1. **Most of the problem is the Tom model itself, not our pipeline.** At Expression 0 there is no DSP at all, and Tom already has 3× more speech breaks than Pierre (2.3/s vs 0.8/s), which is the staccato "cutting". It also has 2–3.5× more noise in voiced frames, which is the breathy "not clear" sound. Durations come out exactly as rendered: there is no `maxMs` cut in continuous mode, and no chunking.
2. **Changing the Piper noise parameters does not fix Tom.** The grid is in `noise-grid.json` (6 settings × 6 lines). Tom's breaks stay at 2.2–2.35/s at every setting. HNR is best at noise_scale 0.333 (7.0 dB vs 6.3 dB), which still falls short of Pierre's 7.8–8.3 dB. Raising the noise to E's lively values (0.85 / 1.0) adds clicks (1.3 → 2.2 per line) and dips (0.17 → 0.5 per line).
3. **Our pipeline made it worse in three ways.**
   - **Truncated tails.** `trimSilence` kept only 30 ms after the last sample above 0.015 and then stopped with no fade. Every voice ended at around −30 dB, still audible, which sounds like a cut. It is most audible on Tom's breathy final consonants.
   - **PSOLA holes when pitch goes down.** Overlap-add was normalised only where window sum > 1, so lowering the pitch left dips at F0 rate. Contour expansion lowers half of every contour. On Tom, expression raised gaps from 0 to 2 and dips from 3 to 9.
   - **Generic prosody on a male voice.** k reached 1.8 and the mean shift reached +3 st on a 130 Hz voice, using the female 70–500 Hz F0 search.

## Voice choice: **Pierre** (`fr_FR-upmc-medium#pierre`) is the new default male

Licence: CC BY-SA 4.0 (UPMC corpus) is more permissive than Tom's AGPL-3.0. Its ShareAlike clause applies to the voice data, and AutoDub does not redistribute the model: the user's browser downloads it from Hugging Face.

## Fixes
| Fix | Files |
|---|---|
| **Per-voice prosody** with `voiceProsody(p, gender, model inference defaults)`, applied in the worker:<br>• Noise is now **relative to each model's own defaults** (Siwis 0.5/0.333, Tom and upmc 0.667/0.8). This also closes E's open issue 2.<br>• **Male voices never get more noise than their defaults.**<br>• Male: **k is scaled into 1…1.4** (`MALE_MAX_K`), the upward mean shift is ×0.6, and accents are ×0.7. | `offscreen/prosody-dsp.ts`, `piper-worker.ts` |
| **F0 range per gender** (`F0_RANGE`): male 60–250 Hz, female 100–500 Hz, passed as `expressify(…, {gender})`. | `prosody-dsp.ts` |
| **Octave guard.** A grain whose measured period disagrees with the track by more than 0.7 octave keeps ratio 1. Per-grain ratios then go through a 3-point median and a ±0.6 st slew limit. | `prosody-dsp.ts` (`psola`, `smoothRatios`) |
| **Smooth PSOLA.** Grains use a pitch-synchronous **asymmetric Hann** window (left half = distance to the previous mark, right half = distance to the next, each 0.5–1.5 P). The overlap-add is **normalised by the window sum everywhere** (floor 0.35), so pitch-down leaves no holes. Output length still equals input length, so `knownMs` stays exact. | `prosody-dsp.ts` |
| **Lines are never cut.** The tail margin is now 60 ms (the lead stays 30 ms). Every line gets a **25 ms raised-cosine fade-out** and a 4 ms fade-in (`fadeEdges`). This applies at all Expression levels, so Expression 0 is no longer byte-identical to v1.1: it now gets the 60 ms tail and the fades too, which is intentional. | `offscreen/piper.ts`, `piper-worker.ts` |
| **Default male = Pierre.** Pierre is now `recommended` and Tom is not. The French "Download voices" button fetches Siwis + upmc (140 MB). `neuralVoice('model#speaker')` now resolves any speaker of a known multi-speaker model. | `content/voice/neural-catalog.ts` |

## Unit tests (`tests/unit/m-*.test.ts`)
- **90 Hz synthetic male vowel with a strong 2nd harmonic:**
  - every tracked frame is within 1 st of 90 Hz, with no octave error;
  - PSOLA shifts of +3/−3/+2/−2/+5 st land within ±0.5 st, measured by an independent estimator;
  - the length is exactly the input length;
  - the max sample jump stays at or below what the pitch change implies (+30 %);
  - pitch-down keeps a steady per-period RMS (≥ 0.95) and stays within 1 dB of the input level;
  - ratio 1 reconstructs the input (< 2 % error);
  - a per-grain ratio flip is slew-limited;
  - male `expressify` keeps the length exact.
- `voiceProsody`: male k ≤ 1.4, male noise ≤ the model defaults, Siwis noise relative to its defaults.
- Line edges: the 60 ms tail and a ≥ 20 ms fade that ends on 0.
- Catalog: the default male is `fr_FR-upmc-medium#pierre`, Tom is still listed, and Siwis is unchanged.
- Three older assertions were updated for the new default: `p-neural` (Tom → Pierre), `p-popup` (127 → 140 MB) and the e2e popup check.
