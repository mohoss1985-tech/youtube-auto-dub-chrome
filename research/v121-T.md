# v1.2.1: T, free offline translation (2026-11-24)

**The bug.** This is the owner's Chrome 158 (managed profile). On youtube.com there is no `Translator` global, and `LanguageModel` reports `unavailable`. YouTube's `tlang=fr` returns HTTP 429. So no free translator was left, and dubbing failed with "No free English → French translator… or update Chrome".

**The fix.** Opus-MT (Helsinki-NLP, CC-BY-4.0, Marian models converted to ONNX by Xenova) now runs fully offline in the offscreen document, using transformers.js. It is downloaded once (113 MB for en→fr) and is then always available.

## Status
- `npx tsc --noEmit` is clean.
- `npx vitest run` passes: 34 files, 353 tests. The new `tests/unit/t-offline.test.ts` has 13 tests.
- E2E with `AUTODUB_DIST=build-t npx playwright test tests/e2e/t-offline.spec.ts tests/e2e/p-neural.spec.ts tests/e2e/smoke.spec.ts` passes 4/4. The Piper voices still work next to the new worker.
- Built with `node build.mjs --outdir build-t` (36 MB unpacked, +1.2 MB for `mt-worker.js`). `dist/` was not touched. Nothing was committed. The version was not bumped (manifest/package are still 1.2.0, which the lead owns).
- New dependency: `@huggingface/transformers` **4.3.2** (exact, released 2026-10-27, Apache-2.0). It was installed with `--ignore-scripts`. Its Node-only dependencies (sharp, onnxruntime-node) are never bundled.

## Chain (`content/pipeline.ts`)
1. The track is already in the target language: no translation.
2. **YouTube tlang**, one try. A failure or 429 blocks tlang for that video+language for **10 min** (`TLANG_RETRY_MS`). After that one more try is allowed, so a 429 no longer blocks tlang for the rest of the page session.
3. **Chrome Translator in the page.** This is the existing `translateLocal`, which falls back to the MAIN-world bridge.
4. **Offline**, via `OFFLINE_TRANSLATE {texts, from, to}` → SW (`background/offline.ts`, batches of ≤ 16) → offscreen document:
   - **(a)** Chrome's Translator API *in the extension context*. It is used only when `availability()` is `'available'`, because there is no user activation there. A refusal is remembered for the session.
   - **(b)** Otherwise **Opus-MT** in `mt-worker.js`. While the model downloads, the worker answers `{pending, progress}`. The content script polls every 0.7 s (max 20 min, stops when the session stops) and shows **"Downloading French translator (offline, once)… 40%"**, then "Translating to French (offline)…".
5. **OpenAI**, if a key is set.
6. **Error.** The message now names the real cause:
   - The model could not be loaded: "The free offline English → French translator could not be loaded (…). Check that huggingface.co is reachable (a school or company network may block it) and try again, or add an OpenAI key…".
   - There is no model for the pair: "AutoDub has no free offline X → Y translator, and Chrome's built-in translator is not available on this computer…".
   - "Update Chrome" is never suggested.
- **ASR tracks** keep their old rule: our own translators run before tlang (Chrome page → offline → tlang → OpenAI).
- **Progressive streaming is kept.** Offline translation does the first **20 lines from `currentTime`** first (sent as 10 + 10), then chunks of 32. The rest arrive through `onUpdate`, and the cache is written at the end.
- F's `speechFriendly` polish runs on every translated line. E's `shout`/`emph` flags, `newSpeaker`, `source` and `id` are all kept (tested). **The cache key changed to `lines:<id>:<lang>:4`.**

## Offscreen / worker
- `offscreen.ts` handles the new op `'mt'`: it tries the Chrome Translator first, otherwise it uses the module worker `mt-worker.js`. The Piper path is unchanged. There is a test hook `globalThis.autodubOffline`.
- `mt-worker.ts` uses transformers.js `pipeline('translation', repo, {dtype:'q8', device:'wasm'})`:
  - The model is cached in the extension origin (Cache API `autodub-mt-v1`).
  - `useWasmCache=false`, because blob-URL factories are blocked by the CSP.
  - `wasmPaths` points to the local `ort/ort-wasm-simd-threaded.wasm`.
  - Threads: min(3, cores − 1), with crossOriginIsolated.
  - A failed download is held for 60 s, then retried.
- **Reusing ORT:** `build.mjs` aliases transformers' `onnxruntime-web/webgpu` import to the top-level **onnxruntime-web 1.31.1** `ort.wasm.bundle.min.mjs`, and `onnxruntime-common` to 1.31.1. The worker therefore uses the same 14.8 MB `.wasm` that is already shipped for Piper: no new wasm, no JSEP, no CDN. The bundle has no remote `import()`. The jsdelivr default is overwritten before any session is created.
- **Pairs (`shared/offline-mt.ts`):** en→fr, en→es, en→ar, fr→en, es→en, ar→en, tr→en, all `Xenova/opus-mt-*` q8 at about 110 MB each. Other pairs go through English (e.g. fr→es = fr→en, then en→es).
  - **en→tr is not offered.** The only ONNX conversion is `onnx-community/opus-mt-tc-big-en-tr` at 530 MB in q8, and `Xenova/opus-mt-en-tr` does not exist. en→tr falls through to OpenAI or the error.
  - **en→ar does not use `>>ara<<`.** transformers.js 4.x's fast tokenizer splits that token into pieces and the model echoes "<>ara>>". Without the token it already produces Standard Arabic (measured).
- **One sentence per generate call.** Batched (padded) generation was 2.5× faster (47 ms/line), but it changed words (fr: "sa 40 000e **note**" instead of "son 40 000e **point**") and made en→ar add junk ("،، يا سيدي."). `num_beams: 4` gave output identical to greedy, so greedy is used.

|---|---|

| Unsupported pair (de→fr) | clean `NO_TRANSLATION` |

### Five en→fr pairs, unedited, for the owner to judge
| English (after F cleanup) | Opus-MT French |
|---|---|
| I just bought a private island! | Je viens d'acheter une île privée! |
| Chandler, you have ten seconds to grab as much money as you can. | Chandler, tu as dix secondes pour prendre autant d'argent que tu peux. |
| LeBron James just scored his 40,000th point. | LeBron James vient de marquer son 40 000e point. |
| Whoever stays in the circle the longest wins $500,000. | Celui qui reste dans le cercle gagne 500 000 $. *("le plus longtemps" dropped)* |
| Steph Curry pulls up from half court and it is good! | Steph Curry sort de la demi-tribu et c'est bon! *(wrong: sports slang)* |

**Verdict.** Plain everyday sentences come out well. Sports idioms and slang are weak:
- "down by three with ten seconds left" → "en bas de trois avec dix secondes à gauche"
- "Give it up for the winner!" → "Laissez tomber pour le gagnant!"
- "going wild" → "en train de devenir sauvage"
- one small grammar error: "Si vous vous abonner"

For kids it is understandable and free. OpenAI (with a key) and Chrome's translator remain higher in quality where available.

The es/ar samples are in the test output (`T_ALL=1`). Example: "¡Acabo de comprar una isla privada!" / "لقد اشتريت لتوي جزيرة خاصة".
